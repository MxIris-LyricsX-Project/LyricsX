# What's New

This version adds desktop widgets, an Apple Music-style lyrics window and lyrics translation.

## Upgrading

- This version requires macOS 12 or later.
- Menu bar lyrics now hide while music is paused, following **Disable lyrics when: Music is not playing** in **Preferences → Display**.
- Lyrics searches now leave out bracketed parts of song titles; turn off **Strip brackets from search title** in **Preferences → General** to keep them.

## New

- Desktop widgets in four sizes show the current lyrics, on macOS 15 or later.
- An Apple Music-style lyrics window, with the cover beside animated lyrics, can be turned on in **Preferences → Lab** on macOS 15 or later.
- The menu bar shows playback buttons next to the lyrics; turn off **Show playback controls in menu bar** in **Preferences → Lab** to hide them.
- **Lyrics translation** in **Preferences → Lab** fills in missing translations using System Translation on macOS 26 or an OpenAI-compatible service.
- **Display language** picks which translation is shown.
- Apple Music can serve as a lyrics source with word-by-word timing once you add your user token in **Preferences → Lab**.
- **Next Lyrics Candidate** switches to the next search result, from the menu or a keyboard shortcut.
- **Preferences → Source** offers three ways to rank results: by match score, by source order, or by score with source order breaking ties.
- **Preferences → General** can now always search again instead of using saved lyrics, and write your edits back to lyrics files beside the track.
- The lyrics window has a right-click menu to search for or edit the lyrics.
- **Preferences → Lab** can recover original song names through MusicKit and favor lyrics whose cover matches the song.
- **Receive beta updates** in **Preferences → General** lets you try new versions early.

## Improvements

- Lyrics you pick by hand now stay with the song, even when it has embedded lyrics or a lyrics file beside it.
- Menu bar lyrics use much less CPU on macOS 26 and later.
- Search results rank instrumental and karaoke versions below the original song.
- The lyrics window now appears on every Space.
- Furigana uses the kana supplied by the lyrics source when there is one.

## Fixes

- **Wrong Lyrics** and **Disable Lyrics for Entire Album** no longer delete your own lyrics, whether in a file beside the track or in Music.
- Fixed lyrics coming back after **Disable Lyrics for Entire Album**.
- Fixed **Search Lyrics** applying a different result than the one selected, or applying it to a song that started in the meantime.
- Skipping a song during a search no longer rewrites the next song's lyrics in Music.
- Fixed a crash when the lyrics window's font is no longer installed.
- The menu bar no longer shows the previous song's last line until the next song's lyrics begin.
- Fixed a crash when dragging text from another app onto the list in **Preferences → Source**.
- Lyrics no longer get stuck on the last line when a song repeats.
- The desktop lyrics highlight is no longer clipped, misaligned or restarted by small position corrections.
- The last word of a word-timed line now fills in the desktop lyrics and on the Touch Bar.
- Lyrics no longer jump back to the first line on pause with some players.
- With the system Now Playing source, lyrics no longer jump back on pause or run ahead after resuming.
- Lyrics search no longer misjudges the length of songs playing in Spotify.
- QQ Music lyrics no longer lose text around parentheses.

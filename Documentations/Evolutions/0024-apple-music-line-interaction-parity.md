# Draft - 歌词面板的悬停与按下反馈、非当前行亮度和翻译样式对齐 Music 26.6

- **状态**: In Progress
- **创建日期**: 2026-10-17
- **最后更新**: 2026-10-17

## 摘要

2026-10-17 用 26.6 的 `Music.i64` 和视图层级抓取核对面板，发现四处差距：鼠标悬停和按下一行时我们没有任何反馈；
非当前行靠整行 0.55 的不透明度变暗，Music 是把文字颜色设成白 40%；翻译行的字重、颜色、间距都不同，
和原文相同时也照样显示。这次把这四处按 Music 的做法补齐。间奏圆点、作词行等其余差距不在本提案内。

## 方案

数值全部来自 `/Volumes/RE/AppleMusic/26.6/Music.i64`，函数地址会写进
[AppleMusicLyricsAnimation.md](../Internal/AppleMusicLyricsAnimation.md)。

- **行的图层结构照 Music 改**：Music 每一行是「行图层（带模糊和亮度滤镜、常开光栅化）→ 按下背景 +
  容器 → 主歌词 + 翻译」。我们的行现在只有主歌词在自己的图层里，翻译是行视图 `draw(_:)` 直接画的，
  按下时没法和主歌词一起缩放、变暗。改为：行视图里放一个 flipped 的 layer-hosting 视图，托管的根图层下挂
  按下背景（用到时才建，放最底层）和一个容器图层；容器里放现有的 `SyncedLyricsLineContentLayer` 和一个
  新的翻译图层。滤镜和光栅化仍在行视图的 backing layer 上。
- **悬停**（`mouseEntered:` → `sub_10019EEDC`）：只对非当前行生效，立即（没有动画）把模糊去掉，并给行加
  `colorBrightness` 滤镜、`inputAmount = 1`（滤镜第一次悬停时才装上）。移出时立即恢复。悬停中的行变成
  当前行时，用模糊同款的 0.12 秒曲线撤销。
- **按下**（`setHighlighted:` → `sub_10019D630`）：
  - 背景：白 8%、连续圆角 16，比「文字列宽 × 内容高」四周各大 16 pt。
  - 不透明度：背景 0 → 1，容器 1 → 0.85。按下用 (0, 0)(0.55, 1) 0.2 秒，松开用 (0.25, 0.1)(0.25, 0.1) 0.3 秒。
  - 缩放：容器和背景一起缩到 0.95（以行的中心为基点），按下弹簧 1 / 322 / 24，松开 2 / 300 / 50。
  - 松开的两段动画都晚 0.1 秒开始，所以快速点一下也看得到按下的样子。按住期间模糊去掉。
- **非当前行亮度**：去掉整行 0.55 的不透明度，行始终是 1。改由主歌词「未唱颜色」那层决定：非当前行
  白 40%，当前行未唱部分白 50%、已唱部分白 100%（后两者不变）。切换当前行时，未唱颜色在 0.4 和 0.5
  之间变，已唱的扫光以不透明度淡入淡出，选中和取消选中都走切行弹簧 1 / 100 / 18（`sub_10016D164`）。
  旧做法是已唱部分瞬间消失、整行再从 1 淡到 0.55。
- **翻译**（`sub_10017A8D0`、`sub_10017A270`）：粗体，字号仍是主字号 × 0.57；当前行白 50%、其他行白 40%，
  切换当前行时立即变（Music 也是）；离主歌词 7 pt（原来 4 pt）；和原文忽略大小写后相同就不显示。
  翻译改由容器里的图层来画，按下时和主歌词一起缩放、变暗。

没有问、直接采用的假设：

- **0.4 和 0.55 做成可切换**：0.55 是当初对着 26.5.2 录屏校准的，和 26.6 的 0.4 冲突。默认用 0.4，
  另加一个隐藏的 defaults 键能切回 0.55，方便并排对比；做法同 `AppleMusicLyricsCascadeVariant`，
  每次切行时读取，不用重启。
- **悬停在面板不是前台窗口时也生效**：面板经常浮在别的 app 上面，只在前台时生效就很少看得到。
- **点击只在松开时仍在这一行里才跳转**（现在就是这样）。Music 拖出行外松开也会跳转，这点不照抄；
  按住拖出行外时按下效果收回，拖回来再出现。
- **模糊按状态推导**：当前行、悬停中或按下中的行不模糊，其余按切行时算出的值。Music 是在按下时记住
  原半径、松开时写回，点完一行在跳转生效前会先模糊一下再清掉；推导的写法看起来一样，但没有这一下。
- 文字左右边距（Music 20、我们 24）、歌词列宽这些已知差距这次不动。

验证：

- 不开窗口的单元测试：断言上面这些数值、翻译查重规则、明暗变体的读取。
- 改造现有的 AppKit 探针，让它们从新的图层结构里找到主歌词图层。再新增一组探针：把一行放进窗口，
  模拟悬停、按下、松开和切换当前行，检查图层树和最终取值。这几组探针要开窗口，跑之前先征得同意。
- 包和整个 app 的 Debug 构建。没有授权不启动 app，实际观感请你来看。

## 决策日志

| 日期 | 决定 | 理由 |
|------|------|------|
| 2026-10-17 | Created as Draft | JH：「先做鼠标悬停和按下的反馈（我们完全没有）、非当前行的亮度、翻译行的样式。」 |
| 2026-10-17 | 先改行的图层结构，再加悬停和按下 | Music 按下时把主歌词和翻译一起缩放、变暗；我们的翻译画在行视图自己身上，不挪进单独的图层就做不到。直接对行视图的 backing layer 设 transform 又违反「AppKit 拥有视图几何」的约定 |
| 2026-10-17 | 选中切换的颜色动画用切行弹簧，不用文档里记的 0.28 秒曲线 | 重新反编译确认：0.28 秒曲线只驱动行的 transform，而 pretty 模式下 transform 恒为单位矩阵，看不出来；文字颜色走的是 `LyricsSpecs` 里的切行弹簧 |
| 2026-10-17 | 悬停不加动画 | 之前的核对记成「0.12 秒去模糊」，复查发现 `mouseEntered:` 调用时传的是 `animated: false`，只有「悬停中的行变成当前行」这条路径才带动画 |
| 2026-10-17 | Accepted → In Progress | JH：「开工」。开窗口的探针还没得到运行许可，先只跑构建和不开窗口的测试 |
| 2026-10-17 | `LayerPropertyAnimator` 改为按 model 的前后差决定动哪些属性，起点仍取 presentation | 按下时两个 animator 在同一轮里作用于同一对 layer。原来拿 presentation 与新 model 比较，第二个会把第一个刚写、尚未提交的 opacity 当成变化，用弹簧换掉 cubic 曲线。既有调用点都只改自己写的属性，行为不变 |
| 2026-10-17 | 翻译画成白色，用翻译图层的 opacity 表达 0.5 / 0.4 | Music 是切行时重建属性串；改 opacity 不用重画文字，切行那一刻主线程少一次排版，字形不重叠时看起来一样 |
| 2026-10-17 | 亮度动画也像 blur 一样暂停光栅化；当前行退回非当前行时若指针还在上面，亮度沿同一曲线加回 | 光栅化的位图包含滤镜，动画中不关会定格在中间值。第二条是「模糊按状态推导」的同一思路，Music 这一侧没有核对 |
